# 跨应用选区捕获兼容

## Goal

在保留现有误触过滤和内存隐私边界的前提下，让 ClipAll 在原生控件、WebKit、Chromium / Electron 以及完全不暴露可用 Accessibility 节点的 App 中，通过明确的选词手势取得选中文字并显示浮窗。

## Confirmed Facts

- 自动取词只响应拖选、双击 / 多击和 Shift-click；普通单击不触发捕获。
- 捕获顺序为 AX 焦点 / 鼠标命中候选及有限父级遍历，随后才可能进入一次 `Command-C` 剪贴板回退。
- 剪贴板回退会在内存中完整快照原剪贴板，使用 `changeCount` 检测目标复制和并发写入，只在安全时恢复；选中文字不写磁盘、不进入日志。
- 文件、图片和其他非文本对象即使同时提供纯文本表示，也会被剪贴板类型过滤器拒绝。
- 2026-08-11 的 POPO 运行日志显示：正文双击四次均为 `noFocusedElement`，120ms 后仍不可读，鼠标位置 AX 命中链为空。该 App 不是 AX 建立较慢，而是这块正文没有可用于判定文字表面的 AX 节点。证据见 `research/popo-runtime-evidence.md`。
- 当前双击谓词把“明确命中非文字控件”和“AX 完全不可用”都判为拒绝，导致 POPO 这类 App 无法进入受约束的剪贴板回退。

## Requirements

### R1. 分层捕获保持不变

1. 优先读取焦点元素与来源 App 焦点元素的 AX 选区。
2. 同时检查鼠标位置命中的 AX 元素，并在确定的深度上限内查找父级选区所有者。
3. 支持直接选中文字、Range / 参数化字符串、Text Marker Range 及对应边界。
4. AX 成功时不得发送 `Command-C`。

### R2. 明确手势的回退策略

- 拖选：AX 失败后允许进入剪贴板回退。
- 双击 / 多击：用一个命中谓词决定是否进入剪贴板回退：
  - 路径为空，表示 AX 完全无法判断，允许进入受约束的回退；
  - 路径中存在按钮、列表行、Tab、菜单项或可操作动作等明确非文字证据，拒绝回退；
  - 路径中存在文字选区语义且整条有限路径没有明确非文字控件，允许回退；
  - 路径非空但没有文字选区语义，拒绝回退。
- Shift-click：AX 失败后不进入剪贴板回退，避免复制列表项或旧焦点内容。
- 不按 bundle identifier 为 POPO 或其他单个 App 写特例。

### R3. 剪贴板与隐私边界

- 只有上述明确手势与全局兼容取词开关共同允许时，才发送一次 `Command-C`。
- 用户可按 App 排除剪贴板回退。
- 复制结果必须产生新的 `changeCount`、包含非空纯文本、保持稳定，且不含已知文件 / 图片 / 非文本对象类型。
- 原剪贴板的每个 item / type 数据只在内存中物化；没有并发写入时恢复全部内容，检测到第三方新写入时不得覆盖。
- AX 能识别到 `AXSecureTextField` 时必须拒绝读取与回退。
- 当目标表面完全不暴露 AX 时，ClipAll 无法独立证明它是否为安全输入区；此时只读取来源 App 响应用户 `Command-C` 主动提供的内容。无法接受该边界的 App 可通过排除列表关闭回退。
- 日志只能记录触发类型、分类、bundle identifier、错误枚举和是否成功，不得记录选中文字、剪贴板内容、控件标题或路径。

### R4. 误触控制

- 普通单击不触发回退。
- 有 AX 证据的文件树行、按钮、Tab、菜单和其他可操作控件必须在发送 `Command-C` 前被拒绝。
- AX 完全不可用时，`Command-C` 没有产生新纯文本或产生非文本对象，必须静默失败且不显示浮窗。
- 保留相同选区的去重窗口，避免同一手势重复发布。

## Out of Scope

- OCR、屏幕截图取词及屏幕录制权限。
- 私有 API、DOM 注入或单 App bundle 硬编码。
- 支持远程桌面画面、视频字幕、Canvas 绘制文字等没有系统选区语义的内容。
- 保证完全不暴露 AX 的第三方 App 中所有自定义“复制”命令都能区分文字与业务对象；这类剩余误触通过剪贴板类型过滤和按 App 排除控制。

## Acceptance Criteria

- [x] POPO 正文双击在 AX 焦点、延迟重试和命中链均不可用时，仍能通过一次内存剪贴板回退显示正确浮窗。
- [x] 原生 AX 文本控件、输入框、WebKit 和 Chromium / Electron 文本继续通过 AX 或受约束回退显示浮窗。
- [x] IDE 文件树行、按钮和 Tab 的双击继续被明确非文字命中证据拒绝，不显示浮窗。
- [x] 空 AX 命中链允许双击回退，非空但无选区语义的命中链拒绝双击回退。
- [x] 普通单击与 Shift-click AX 失败时不发送复制回退。
- [x] 文件、图片、动态文件对象、空复制和复制超时继续静默失败，原剪贴板按现有并发规则恢复。
- [x] 捕获过程不创建包含选中文字或剪贴板内容的磁盘文件，日志不输出其内容。
- [x] 临时 `[DEBUG-popo-selection]` 探针从产品代码中移除。
- [x] `Scripts/verify-overlay-state.sh`、`Scripts/verify-all.sh` 与 SwiftPM `ClipAll` target 构建通过。
- [x] 当前构建通过 `Scripts/install-local-app.sh` 稳定签名安装到 `/Applications/ClipAll.app` 后，用户完成 POPO 正文、IDE 文件树、VSCode 正文 / Tab 和输入框手测。
- [x] 用户明确表示手测通过前，不 commit、不归档任务、不声称完成。
