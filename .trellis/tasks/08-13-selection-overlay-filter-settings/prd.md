# 浮窗过滤与应用级取词设置

## Goal

减少双击等高频操作造成的浮窗误弹，让用户能按触发方式和来源 App 明确控制自动浮窗，同时保留快捷键与菜单主动取词。

## Background

- 普通单击当前不会触发捕获；拖选、双击/多击和 Shift-click 会产生不同的 `PointerSelectionIntent`（`PointerSelectionGesture.swift:9-63`）。
- 双击/多击已有 AX 命中链过滤，按钮、Tab、菜单、列表行等阻断角色会在剪贴板回退前被拒绝；AX 直接返回真实选区时仍会显示（`SelectionCaptureService.swift:46-93,138-193`）。
- 当前通用设置中的“排除应用”只关闭该 App 的剪贴板回退，不能阻止 AX 成功后的浮窗（`SettingsStore.swift:159-174`、`AppEnvironment.swift:83-100`）。
- 现有全局监听、兼容取词与应用排除已使用 `UserDefaults` 持久化；设置页已有 `.applicationBundle` 选择器，可直接复用（`GeneralSettingsView.swift:81-121,191-209`）。
- 拖选原先直接允许剪贴板回退，已识别的图片目标也会收到 ClipAll 合成的 `Command-C`；随后图片结果被拒绝并恢复旧剪贴板，表现为用户复制图片后仍粘贴出旧图片。

## Requirements

### R1. 独立取词设置页

- 设置侧栏新增“取词”，作为默认打开页面。
- 所有全局与应用级规则只在设置页管理；浮窗、菜单栏菜单和来源 App 内不增加快捷配置入口或提示。
- “取词”页承载自动显示、触发方式、应用规则、固定过滤帮助说明和兼容取词。
- “通用”页保留全局快捷键、菜单栏/Dock 入口和辅助功能权限，不重复展示取词策略。
- 复用现有 `ClipAllSectionCard`、间距、颜色和控件样式，不新建设计系统或自定义导航框架。

### R2. 全局自动显示规则

- 保留现有自动监听总开关。
- 新增“拖选文字后显示”开关；同时控制拖动选择与 Shift-click 扩展选区，默认开启。
- 新增“双击/多击文字后显示”开关，默认开启。
- 关闭某类触发只抑制自动浮窗；注册快捷键和菜单手动取词仍按现有主动路径执行。

### R3. 应用级规则

- 用户可从 `.app` 包选择来源应用；拒绝 ClipAll 自身和无 Bundle ID 的包。
- 每个 App 支持三态规则：
  - `跟随全局`：使用全局拖选与多击开关。
  - `仅拖选`：允许拖选和 Shift-click，拒绝双击/多击。
  - `永不自动显示`：拒绝所有鼠标自动触发。
- 应用级规则只影响自动鼠标触发，不禁用快捷键或菜单手动取词。
- 新增 App 默认使用“跟随全局”；全局拖选、双击/多击与兼容取词均默认开启，保持当前行为。
- 现有兼容取词排除名单不转换为“永不自动显示”；它继续只控制剪贴板回退，并在同一个应用规则列表中统一管理。
- 删除应用规则时同时移除其显示策略与兼容取词排除状态，使其恢复全局默认。

### R4. 固定安全过滤

以下情况保持不可关闭，并在设置页以简明说明列出：

- 普通单击、未形成有效选择意图或重复选区。
- 密码/安全输入框、空白或失效选区、来源 App 已切换。
- 按钮、Tab、菜单、文件/文件夹、图片及其他已识别的非文本对象。
- 已识别的非文本目标必须在发送合成 `Command-C` 前拒绝，不能依赖复制后恢复兜底；自动拖选或多击的 AX 命中路径为空时也不得回退，显式快捷键与菜单主动取词仍可使用兼容取词。
- 剪贴板事务超时、取消、竞争写入或无法安全恢复。

### R5. 决策顺序

```text
固定安全过滤 > 应用级规则 > 全局触发规则 > AX/兼容取词 > 浮窗
```

- 应用规则必须在自动捕获前生效，避免被禁用 App 仍触发 AX 或剪贴板副作用。
- 来源 App 在捕获期间变化时继续按现有失效规则拒绝结果。
- 日志只记录触发类型、bundle identifier、抑制原因和错误枚举，不记录选中文字或剪贴板正文。

## Acceptance Criteria

- [x] AC1：关闭“双击/多击”后，任意 App 双击文字不显示浮窗；拖选仍按全局设置工作。
- [x] AC2：关闭“拖选”后，拖动和 Shift-click 不显示浮窗；双击仍按全局设置工作。
- [x] AC3：App 设为“仅拖选”时，即使全局多击开启，该 App 双击不弹、拖选可弹。
- [x] AC4：App 设为“永不自动显示”时，拖选、双击和 Shift-click均不弹；快捷键和菜单主动取词仍可用。
- [x] AC5：App 设为“跟随全局”时使用全局开关；删除规则后恢复同样行为。
- [x] AC6：升级后全局监听、触发开关和兼容取词保持默认开启；原兼容取词排除 App 仍只禁用复制回退。
- [x] AC7：普通单击、安全输入、阻断控件、文件/图片、空白、重复与失效选区继续固定过滤；已识别图片及空 AX 路径的自动拖选、多击在发送合成 `Command-C` 前拒绝，UI 不允许关闭这些安全规则。
- [x] AC8：设置重启后保持；无 Bundle ID、ClipAll 自身和损坏的持久化值被安全忽略。
- [x] AC9：定向验证、全量验证和 Swift 构建通过；安装到 `/Applications/ClipAll.app` 后完成全局规则、应用规则和主动取词实测。

## Out Of Scope

- 最短字数、关键词、正则、语言、全屏状态、窗口标题或网站级过滤。
- App 专属 AX 特判、固定延迟、OCR、浏览器扩展或进程注入。
- 修改浮窗内容、能力路由、动画、插件或翻译行为。
- 在浮窗、右键菜单、首次启动提示或运行时通知中管理过滤规则。
- 让用户关闭密码框、文件对象等安全过滤。
