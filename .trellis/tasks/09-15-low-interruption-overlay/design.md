# 低打扰取词浮窗设计

## Boundaries

本阶段只调整自动捕获时机和现有浮窗的信息层级：

- `SelectionMonitor` 负责安静确认期与后续鼠标操作取消。
- `SelectionOverlayView` 负责 `280pt` 统一宽度、收缩态直显能力和“更多”中的溢出操作。
- `CapabilitiesSettingsView` 只同步预览与说明，不改变固定能力存储。
- `SettingsStore`、AX 捕获、剪贴板回退、应用规则和插件合同保持不变。

## Trigger Flow

```text
鼠标拖选/多击结束
  -> 现有策略与来源校验
  -> 等待 120ms
     -> 若发生新 mouseDown：取消，静默结束
     -> 否则：执行现有 AX/剪贴板捕获
  -> 现有去重与浮窗发布
```

菜单主动取词保持零等待；全局快捷键保持现有 `20ms` 等待。取消是正常控制流，不记录错误，
也不触发权限或失败提示。

## Compact Surface

```text
收缩态： [复制] [固定 1] [固定 2] | [+]
更多态： [粘贴] [固定 3] [固定 4] [插件搜索与发现]
```

- 固定能力仍最多四个，原数组顺序不变；只在渲染时用 `prefix(2)` 与 `dropFirst(2)` 分层。
- “更多”继续排除全部固定能力的插件发现结果，溢出固定能力由顶部快捷操作区单独展示，避免重复。
- 收缩、更多、执行中与结果态统一使用 `280pt`，沿用现有顶部锚点和向下展开逻辑。
- 较长能力名称允许在操作按钮中收紧或省略，但完整名称继续由 hover help 和辅助功能标签提供。
- 不增加动画、测量器、动态宽度状态或新的持久化字段。

## Compatibility And Rollback

- `120ms` 只影响鼠标自动取词；主动入口与捕获语义不变。
- 现有固定能力超过两个时只改变入口位置，不删除数据。
- 若实测延迟明显，可只回调安静期常量；若 `280pt` 影响结果可读性，可独立恢复宽度，
  两项无数据迁移且可分别回滚。

## Verification

- 自动验证等待期内不捕获、新 mouseDown 取消、正常到期仍捕获。
- 现有手势、应用规则、快捷键、AX/剪贴板验证继续通过。
- Swift 构建覆盖 SwiftUI 层级与 AppKit 协调器。
- 安装真实 App 后验证连续点击不抢弹、正常拖选/双击可用、零到四个固定能力均可达、
  展开不横向或纵向抖动。
