# 降低取词浮窗打扰感

## Goal

在保留“选中或双击文字后自动显示”能力的前提下，降低浮窗抢在连续操作中出现的频率，
并缩小收缩态的视觉占用，让自动浮窗更接近低打扰辅助工具。

## Confirmed Facts

- `SelectionMonitor.capturePointerSelection` 当前在鼠标操作结束后只等待 `45ms` 即开始捕获。
- 新一轮 `handlePointerDown` 不会取消上一轮仍在等待的自动捕获；只有下一次捕获调度时才会取消。
- 相同文字、来源 App 和选区范围仅在 `1.2s` 内去重，超过后允许再次发布。
- 收缩态和展开态共用 `SelectionOverlayView.expandedWidth = 324`。
- 收缩态固定展示复制、粘贴、全部已固定能力和“更多”；用户最多可固定四个能力。
- 现有布局合同要求操作栏保持 `36pt` 高、展开只向下增加内容且不重建窗口。

## Requirements

### Quiet Trigger

- 鼠标自动取词在手势结束后进入约 `120ms` 的安静确认期，再执行已有 AX/剪贴板捕获。
- 安静确认期内发生新的鼠标按下时，取消上一轮待执行的自动捕获；不得先弹出再关闭。
- 菜单主动取词和全局快捷键不增加等待，也不受自动捕获取消影响。
- 保留现有 AX、兼容取词、应用规则和剪贴板恢复合同，不增加 App 特判。
- 首版保留现有 `1.2s` 相同选区去重，不引入“永久不再显示”状态。

### Compact Surface

- 收缩态和展开态统一调整为 `280pt` 宽，避免展开时横向移动。
- 高度继续保持 `36pt`；展开仍只向下，不新增出现、消失或尺寸动画。
- 不删除用户现有固定能力数据，不改变最多固定四个能力的持久化合同。
- 收缩态保留图标和文字，不采用全图标工具栏。
- 收缩态直接展示“复制”、排序最前的两个固定能力和“更多”。
- “粘贴”与第 3、4 个固定能力放入“更多”；用户继续通过现有固定能力排序决定哪两个常驻。
- 所有移入“更多”的操作保留文字、图标、辅助功能标签和原执行行为。

## Acceptance Criteria

- [x] 自动鼠标取词在安静确认期结束前不调用捕获服务。
- [x] 安静确认期内的新鼠标按下会取消待捕获任务，且不发布浮窗。
- [x] 没有后续操作时，拖选和双击仍在可感知的短延迟后正常显示。
- [x] 菜单取词、全局快捷键、应用规则、AX 捕获和兼容复制行为保持不变。
- [x] 收缩态和展开态均为 `280pt` 宽，不发生横向尺寸跳变。
- [x] 收缩态保留复制和前两个固定能力；粘贴及其余固定能力可从“更多”执行。
- [x] 零到四个固定能力均无控件溢出或不可达操作；长名称可省略显示但保留完整提示，
  现有固定顺序和数据不丢失。
- [x] 展开/收缩保持顶部锚点，不产生横向或纵向抖动，不增加动画。
- [x] 定向验证、Swift 构建和 `git diff --check` 通过。
- [x] 使用稳定 `ClipAll Local Development` 签名安装到 `/Applications/ClipAll.app`。
- [x] 用户在真实 App 中确认打扰感降低后，才允许 commit 和归档。

## Out of Scope

- 修改文字命中置信度、AX 角色过滤或剪贴板类型分类。
- 新增按 App 的延迟、尺寸或动作数量配置。
- 重做展开内容、结果卡片或插件体系。
- 将相同选区永久标记为已处理。
