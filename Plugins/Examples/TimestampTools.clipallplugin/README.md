# 时间工具

ClipAll 外置插件参考实现，提供：

- `时间戳 → 日期`：严格识别 10 位秒级和 13 位毫秒级 Unix 时间戳。
- `日期 → 时间戳`：严格识别带时区 ISO 8601、常见数字日期和 `yyyy年M月d日` 中文日期。
- 插件配置：系统时区 / UTC；标准 / ISO 8601 / 中文日期显示。

这个目录可以直接通过 ClipAll 的“导入插件”或开发者模式“加载未打包插件”选择。它不依赖主 App 的时间转换 Swift 类型，所有执行都经 manifest/runtime v2 合同完成；handler 只接收文字，配置通过自身稳定 ID 调用 `App.getPluginEnv` 读取。

无时区日期按插件当前时区配置解释并在结果中标注。脚本不会访问网络、文件、剪贴板或 Accessibility。

插件版本 `1.1.0` 起，`plugin.json` 使用受限的 `dateFormat` 输入匹配器声明日期格式。修改或新增同类格式后重新载入插件即可更新推荐规则，不需要重新编译 ClipAll。
