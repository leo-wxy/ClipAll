# 时间工具

ClipAll 外置插件参考实现，提供：

- `时间戳 → 日期`：严格识别 10 位秒级和 13 位毫秒级 Unix 时间戳。
- `日期 → 时间戳`：严格识别带时区 ISO 8601 和列出的常见日期格式。
- 插件配置：系统时区 / UTC；标准 / ISO 8601 / 中文日期显示。

这个目录可以直接通过 ClipAll 的“导入插件”或开发者模式“加载未打包插件”选择。它不依赖主 App 的时间转换 Swift 类型，所有执行都经公共 manifest 与 runner 协议完成。

无时区日期按插件当前时区配置解释并在结果中标注。脚本不会访问网络、文件、剪贴板或 Accessibility。
